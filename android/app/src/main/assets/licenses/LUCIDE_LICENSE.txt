Notices for the line icons in src/main/res/drawable/ic_*.xml

The icons come from the shared demo design (the Figma file for the iOS,
Android and web demos), which uses Lucide (https://lucide.dev). Their
geometry matches lucide-static releases 0.396.0 through 0.510.0: `house`
first appears in 0.396.0 and `landmark` was redrawn in 0.511.0. The LICENSE
file is identical across that range; it is reproduced below as shipped in
lucide-static 0.468.0, followed by the Feather licence it refers to.
